# Meta広告一覧表テンプレート

`meta_fetch.js` のJSON出力を、この形式のMarkdown表に集約する。

## ヘッダー
```
# Meta広告リサーチ: 「<キーワード>」
調査日: <YYYY-MM-DD> / 国: 日本 / 媒体: FB/IG / 総件数: <resultLine>
```

## 一覧表
| # | 広告主 | 動画 | 掲載開始 | コピー冒頭 | LP | 詳細 |
|---|---|---|---|---|---|---|
| 1 | スピリチュアル×マインドコーチ石丸佐和子 | ▶ | 2024/10/24 | チャネリングを100％習得できる！魂瞬間覚醒… | mitama1111.com | [Lib](https://www.facebook.com/ads/library/?id=915246363844986) |

- 「動画」: `isVideo` を ▶ / 画像 で表記。
- 「LP」: `landingUrl` のドメイン（フルURLは別途保持）。
- 「詳細」: `detailUrl`（ライブラリの該当広告ページ）。

## 集約・示唆（任意・有用）
- 同一広告主の重複クリエイティブはまとめ、**出稿期間の長さ・再ローンチ回数**を添える（＝勝ちパターンの示唆）。
- 広告主ごとに本数を集計し、出稿量の多い順に並べると競合の主力が見える。

## カバレッジ（末尾に必須）
```
---
カバレッジ: 総件数 約N件 / 取得M件(上位サンプル, MAX_ITEMS)
- 主要広告主(出稿量上位): 〇〇, △△, □□
- 無関係で除外: L件（広告主が別テーマも出稿していたもの）
- 注記: Meta(FB/IG)のみ。媒体横断やYouTubeは対象外。
```
